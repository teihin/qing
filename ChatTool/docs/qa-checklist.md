# ChatTool 验收清单

## 玩家端

- 从游戏打开的URL只包含 `d=<AES密文>`，不出现明文玩家ID或昵称；新版过期时间戳被拒绝，旧版无时间戳密文仍可接入且客服资料明确显示旧客户端标记。
- 建立会话后地址栏立即移除玩家密文，仅保留 `/chattool/player?sessionRef=<非敏感引用>`；刷新页面能复用对应HttpOnly会话。
- 普通与VIP入口分别显示对应通道；同一浏览器同时打开两个入口时，各标签页消息不串线。
- 无客服在线时显示“当前没有客服在线”，文字输入、发送按钮和图片/视频/文件入口全部禁用；绕过前端直接请求文字或上传接口返回409 `NO_AGENT_ONLINE`，不能生成消息或媒体记录。
- 客服上线后自动接入，双方不刷新页面即可看到状态和消息。
- iOS Safari、Android Chrome/系统浏览器：相册、现场拍摄、视频、PDF、弱网和重试。
- 关闭/重开浏览器后会话仍在有效期内；过期后要求返回游戏。
- 结束会话后不能再发送，并能提交和更新一次服务评价。

## 客服端

- 同一客服账号先后在两个浏览器登录，第二次登录成功后第一次登录立即提示被顶下线；旧 Cookie 请求返回401，数据库每个客服最多只有一条会话。
- 普通客服只能访问自己活动/历史会话和本通道待接入会话，不能读取其他客服或其他通道会话。
- 主管只能查看自己通道的全部会话，但能在团队管理中查看并设置客服通道；普通客服不能调用团队管理接口。
- 同时多个客服接入同一排队会话时只能一人成功。
- 接待上限、最少会话优先、最久未分配优先正确。
- 客服离线、关闭页面超过心跳阈值、账号停用时会话重新入队。
- 转接只允许目标在线客服；内部备注不出现在玩家端。
- 图片预览、视频 Range 播放、文件下载、快捷回复、输入中、未读数正常。
- 玩家备忘只在客服右栏显示，可新增和删除；玩家端无任何备忘接口或界面。
- “清空记录”二次确认后，双方文字和媒体同时消失，玩家备忘仍在；未确认请求不能删除。
- 构造超过48小时的文字和媒体样本后，维护任务删除数据库记录与磁盘文件，48小时内内容不受影响。

## 安全

- 明文 `playerId` 查询参数不能建立会话；随机密文、错误口令、损坏填充和新版过期时间戳均被拒绝；旧版无时间戳密文仅为现网兼容。
- CSRF 错误、跨来源写请求、超大文件、SVG/HTML、未知媒体被拒绝。
- 玩家不能访问其他会话媒体；普通客服不能访问其他客服会话媒体。
- 日志、响应、审计和前端产物中不存在密码、内部凭据、会话明文令牌。
- 公网地址和全部资源均走 `http://154.37.155.17/chattool/`，无错误的 HTTPS 跳转或跨域请求；Cookie 不带 Secure，但会话 Cookie 必须保留 HttpOnly，全部 Cookie 保留 SameSite。
- 浏览器网络面板确认 `/chattool/api/*`、`/chattool/api/media/*` 和 SSE 均使用 `/chattool/` 前缀；记录纯 HTTP 明文传输风险已由业务接受。
- 验收记录明确说明客户端口令可被逆向，轻量加密不作为可靠玩家身份认证。
- 上传目录不可由 Caddy 静态映射，只能经鉴权媒体接口读取。
- 游戏内 `/player?...&embed=game` 可在 Android、iOS 和 Web/PWA 的 Cocos WebView 内显示，背景半透明且没有“浏览器打开”按钮。
- 游戏内附件区只有图片和视频；Android 系统选择器、iOS 相册选择器、上传进度、发送后回显、客服发送媒体的玩家端回显均逐项验证。
- 跨站 Web/PWA iframe 禁用第三方 Cookie 时仍能发送文字和媒体；完整嵌入会话令牌不出现在地址栏或媒体 URL，媒体票据不能跨媒体或跨会话复用。
- `/player` 允许被游戏 iframe 嵌入；`/agent` 和全部 API 响应仍带禁止 framing 的策略。

## 运维

- MySQL 断开时健康接口失败，守护进程能重启但不会无限写坏数据。
- 备份后在隔离环境恢复数据库与媒体，随机抽查图片、视频和消息对应关系。
- SSE 长连接经过反向代理不缓冲，移动网络切换后可自动重连并补拉记录。
