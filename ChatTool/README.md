# ChatTool 游戏在线客服系统

ChatTool 是独立于游戏服和 XuanManager 的客服产品，全部代码位于本目录。它包含玩家手机 H5、客服工作台、Go 服务端、MySQL 5.7 迁移、实时事件流、媒体存储、自动派单、客服团队管理和客户端加密跳转。

## 已实现功能

### 玩家手机端 `/player`

- 游戏客户端直接把玩家ID、昵称等资料加密后传入，URL中不出现明文资料，不需要KB授权接口。
- 没有客服在线时明确显示“当前没有客服在线”，文字与图片、视频、文件入口全部禁用；客服上线后自动恢复发送。
- 客服上线后自动从队列分配并实时显示客服名称。
- “客服”入口进入普通聊天通道，“VIP充值 / VIP充值2”进入VIP充值通道；同一玩家在不同入口建立相互独立的会话。
- 支持文字、相册图片、现场拍摄、视频、PDF、文本和 ZIP 文件。
- 游戏入口改为 Cocos 内全屏透明 WebView，牌桌仍可见；内嵌模式只保留文字、图片和视频，兼容 Android、iOS 和 Web/PWA，独立网页版继续保留。
- 支持输入中提示、已读时间更新、媒体预览、会话结束和五星服务评价。
- 为触屏、安全区、软键盘和窄屏进行了专门布局；不会要求玩家登录第二套账号。

### 客服工作台 `/agent`

- 独立客服账号登录，主管和普通客服两种角色；同一客服账号严格单点登录，后登录会立即使旧设备退出。
- 在线、离开、离线三种状态；心跳失效后自动离线并重新分配会话。
- “我的会话 / 待接入 / 全部会话 / 已结束”队列、搜索、未读数和实时刷新。
- 文字、图片、视频、文件、快捷回复、内部备注、输入中和已读。
- 自动分配、主动接入、转接、结束会话、接待上限和分配日志。
- 客服账号归属一个服务通道，只能查看、接入、转接和收到本通道消息；主管可为客服选择“普通聊天客服”或“VIP充值客服”。
- 右侧玩家资料列显示昵称、玩家 ID、登录账号、等级、VIP、平台和游戏端扩展信息，并可带玩家 ID 一键跳转 XuanManager 玩家管理页查询和处理；每名玩家还有仅客服可见、跨会话保留的备忘列表，支持新增和删除。
- 主管可创建、启停客服账号，设置角色和最大同时接待量。
- 客服可一键永久清空当前会话内容，玩家端和客服端会实时同步为空；玩家备忘、会话状态、派单日志和审计不会随之删除。

### 安全与数据

- 客服密码使用 bcrypt cost 12；会话只保存随机令牌的 SHA-256，并由数据库唯一约束保证每个客服最多一个有效会话。
- HttpOnly 会话 Cookie、独立 CSRF、SameSite、同源校验、登录和消息限流。
- 新版玩家资料密文默认15分钟失效，网页建立会话后立即从地址栏移除密文参数。为兼容已经发布、尚未携带时间戳的旧客户端，旧格式密文可直接建立会话并在客服资料中明确标记；旧链接因无时间戳无法防重放，待客户端自然升级后可移除该兼容分支。
- 图片和视频按文件头识别，拒绝 SVG、HTML 和其他可执行内联内容；媒体使用不可预测 ID、鉴权下载和范围请求。
- 消息、派单、评价和关键操作均持久化；媒体文件不写入 MySQL BLOB。
- 所有文字、系统消息、内部备注和媒体在创建满48小时后自动永久清除；清理同时删除数据库消息/媒体记录与磁盘文件。
- CSP、客服后台和 API 禁止 iframe、仅玩家入口允许游戏嵌入、禁嗅探、私有缓存以及上传目录 `0700`。

## 本地构建

```bash
cd web
npm ci
npm run lint
npm run build

cd ../server
go test ./...
go vet ./...
CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build -trimpath -ldflags="-s -w" -o bin/chattool ./cmd/chattool
```

运行前复制 `.env.example` 的值到权限受控的运行环境。ChatTool 默认绑定 `127.0.0.1:8893`，由 Caddy 在 `http://154.37.155.17/chattool/` 提供公网 IP 访问；MySQL、8890 和 8893 均不直接开放到公网。前端生产构建已固定使用 `/chattool/` 资源和 API 前缀。

## 游戏接入

游戏不需要新增KB命令。`assets/scripts/UI/panelKefu.ts` 已直接读取当前玩家ID、昵称、等级、平台、角色和房间，使用现有 `Tool.encrypt()` 加密后在游戏内透明 WebView 打开 ChatTool。Android/iOS 原生媒体桥和 Web/PWA 跨站会话兼容范围见[游戏接入说明](docs/game-integration.md)。

当前部署口径按用户确认改为纯 HTTP + 公网 IP：玩家入口为 `http://154.37.155.17/chattool/player`，客服入口为 `http://154.37.155.17/chattool/agent`。`CHAT_COOKIE_SECURE=false`，但 HttpOnly、SameSite、CSRF 和同源校验继续启用；新版玩家资料带有效期，旧版资料仅提供加密混淆兼容。

入口URL里的玩家资料使用AES密文，普通用户无法直接读懂；但口令随客户端发布，只能作为轻量隐藏，无法可靠阻止技术人员伪造身份。纯 HTTP 仍会让后续聊天文字和附件在传输途中以明文暴露，并可能被同链路攻击者窃听或篡改。
