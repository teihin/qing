# 俱乐部逃跑惩罚统计-客户端接口文档

> 创建日期：2026-11-15
> 适用：`settle_mode=realtime` 下，联盟总群主查看本联盟玩家的逃跑罚款
> 服务端口径见 `doc/俱乐部实时结算方案（realtime_settle）.md` §7

## 1. 命令

`查询_逃跑_惩罚_统计`

权限：联盟总群主（`club_union_info.owner_guuid` 本人）；`union_manage` 授权的联盟账号可查被授权联盟；平台 boss 走后台。

## 2. 参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `context` | string | 是 | 回包上下文 |
| `date` | string | 否 | `YYYY-MM-DD`，默认今天 |
| `count` | int | 否 | 每页条数，默认 20 |
| `page` | int | 否 | 页码，从 0 开始 |
| `user_id` | string | 否 | 只看某个玩家的明细 |

## 3. 返回

先回 `GC_OK`（`{"context": "..."}`），再推送路由 **`ClubUnionChengfaStats`**：

```json
{
  "number": 0,
  "count": 2,
  "date": "2026-11-15",
  "union_id": "123456",
  "union_name": "示例联盟",
  "income_gold": 3,
  "total_fen": 350,
  "total": 3.5,
  "player_count": 2,
  "result": [
    {
      "time": "21:38:41",
      "user_name": "玩家A",
      "user_guuid": "580629",
      "bad_fen": 150,
      "bad_money": 1.5,
      "club_id": "710701",
      "club_name": "A俱乐部",
      "union_id": "123456",
      "union_name": "示例联盟",
      "room_id": "772975",
      "room_name": "底皮1/3",
      "settle_batch": "20261115213841_710701"
    }
  ],
  "context": "xxx"
}
```

### 字段说明

| 字段 | 说明 |
| --- | --- |
| `count` | 当日总条数（分页用） |
| `income_gold` | 今日**实际到账**（整元），取自总群主个人积分的 `惩罚收入` 流水 |
| `total_fen` / `total` | 今日玩家**应扣**合计（分 / 元），含尚未凑整的余数 |
| `player_count` | 当日被罚玩家数 |
| `bad_fen` / `bad_money` | 本笔应扣（分 / 元） |
| `club_id` / `club_name` | 玩家入口俱乐部（分盟） |
| `union_id` / `union_name` | 入口俱乐部所属联盟（写入时快照） |
| `room_id` / `room_name` | 牌桌 |
| `settle_batch` | 到账批次；空字符串 = 尚未出账（不足 1 元待结转） |

## 4. 口径与边界

1. `income_gold` 与 `total` 可能差几元：罚款按分累计、整元入账，每个入口俱乐部最多 0.99 元结转到下一批；大厅房或归属异常的罚款进平台，不进总群主。
2. `settle_batch` 是显示层标记，格式 `YYYYmmddHHMMSS_收款俱乐部ID`。同一批可能包含多个玩家/分盟，客户端按批次展示"这批到账多少"，不做单笔金额分摊。
3. 统计只含 `union_id` 非空的行：独立俱乐部的罚款仍归自己创建者，不进总群主统计。
4. 新字段从 2026-11-15 上线后开始有值，历史行 `union_id=''` 不参与统计。
5. `fixed` 模式的罚款（发给最大输家）不写这些字段，不受影响。

## 5. 客户端展示建议

- 顶部：今日到账（`income_gold`）、今日应扣（`total`）、笔数（`count`）、玩家数（`player_count`）
- 列表：玩家 / 金额 / 时间 / 分盟 / 牌桌；`settle_batch` 为空显示"待结转"
- "积分流水"入口跳现有 `查询_俱乐部_积分流水`（总群主俱乐部，`opt_type='惩罚收入'`），该页合计等于 `income_gold`
