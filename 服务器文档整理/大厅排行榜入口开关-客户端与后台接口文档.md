# 大厅排行榜入口开关 —— 客户端与后台接口说明

更新：2026-11-21　分支：`codex/club-ui`

## 需求

大厅「发现」页的「排行榜」按钮改为**按当前俱乐部放行**：后台打开才显示，关闭则隐藏；玩家切换俱乐部后按新俱乐部重新判定。
独立俱乐部自己设置；已加入联盟的俱乐部由**联盟统一设置**（联盟下所有俱乐部跟随）。

## 存储（游戏服哈希表，不需要改游戏服命令）

落库在游戏库 `kbedm.usr_hash_info`，与「暗抽_俱乐部_」「钻石消费价格」同一套机制：

| 场景 | hash_key | hash_content |
| --- | --- | --- |
| 独立俱乐部（未入盟） | `排行榜_俱乐部_<clubId>` | `1` = 显示，`0`/无记录 = 隐藏 |
| 已入盟俱乐部（联盟统一） | `排行榜_联盟_<unionId>` | 同上 |

- 客户端用既有账号命令 `查询_哈希_信息`（`{"header":"查询_哈希_信息","key":"...","context":"..."}`）读取，回包走 `UserHashInfo`。
- 后台不能通过 `/hall/command` 调 Account 命令，因此由 XuanManager 后端直接读写 `usr_hash_info`（写入后回读校验，失败按写入前快照恢复）。
- 同一 key 多行时以最新 `id` 的行为准（MyISAM 无唯一索引）。

## 客户端判定（`assets/scripts/UI/panelMain.ts`）

1. 取当前俱乐部 `ResolveRoomClub()`；没有俱乐部 → 隐藏。
2. 用 `查询_俱乐部_信息` 的 `union_id`（权威）判定归属：
   - 有 `union_id` → 读 `排行榜_联盟_<unionId>`；
   - 确认未入盟 → 读 `排行榜_俱乐部_<clubId>`；
   - 归属未知（俱乐部信息未回）→ 先隐藏，同时补查一次 `查询_俱乐部_信息`，回包后重算。
3. 只有值为 `1`/`true`/`on`/`开` 才显示按钮；查询失败/超时 5 秒按隐藏处理。
4. 触发时机：进大厅、进「发现」页、切换俱乐部、入盟/换盟推送、俱乐部关系变化推送。同一 key 10 秒内不重复查询，切俱乐部强制刷新。
5. 迟到的回包按 key 与当前生效 key 比对，不匹配只更新缓存、不改按钮（避免 A 俱乐部回包把 B 俱乐部的入口点亮）。

## 后台

| 接口 | 权限 | 说明 |
| --- | --- | --- |
| `PUT /api/game/clubs/{clubId}/leaderboard-entry` | `game.club.leaderboard_entry` | 设置独立俱乐部开关；俱乐部已入盟时返回 `CLUB_IN_UNION`，要求去联盟设置 |
| `PUT /api/game/unions/{unionId}/leaderboard-entry` | `game.union.leaderboard_entry` | 设置联盟开关，联盟下所有俱乐部一起生效 |

请求体（与暗抽开关一致）：

```json
{ "enabled": true, "expectedEnabled": false, "note": "运营开榜", "confirm": true }
```

- `expectedEnabled` 必须等于页面当前值，否则 `LEADERBOARD_ENTRY_CONFLICT`；`note` 2–120 字并记入审计。
- 列表接口回包新增字段：俱乐部 `leaderboardEnabled`（已入盟时给的是**联盟生效值**）、联盟 `leaderboardEnabled`。
- 后台入口：俱乐部管理 / 联盟管理行内「排行榜」按钮 + 状态列（`LeaderboardEntryModal`）。
- 原行内「荣耀榜」按钮已移除，荣耀榜配置统一走独立模块「排行榜」（`game.honor_rank`）。
