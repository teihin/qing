# 芒果分类显示 - 客户端接口文档（圈芒 / 休芒 / 揍芒 单状态）

> 消息：`当前_玩家_消息`（服务端 → 客户端 `onMessage`）
> 触发：`玩家_开局_事件` 及后续状态推送；新增字段随现有消息下发，**不新增命令/路由**
> 状态：2026-11-16 按竞品**单状态显示**口径实施并部署测试服，**待重启 baseapp 生效；未提交**
> 配套方案：`doc/芒果分类显示方案.md`
> 适用范围：`积分房卡房 / room_daifen_fangka / 传销扯旋`
> 重要变更：本接口取代同日早先的「三行独立累计」版本。同一时刻只显示 圈芒/休芒/揍芒 中的一行，不是三行同时显示。

## 1. 消息与字段

现有 `当前_玩家_消息` 字段保持不变；本次新增/调整 7 个展示字段：

| 字段 | 类型 | 含义 | 示例 |
| --- | --- | --- | --- |
| `mang_show_state` | string | 0=圈芒(默认)，1=休芒，2=揍芒 | `"0"` |
| `mang_show_xiu_count` | string | 当前链休芒事件次数 | `"3"` |
| `mang_show_xiu_amount` | string | 当前链休芒本类型累计实际金额 | `"1360"` |
| `mang_show_quan_count` | string | 固定 `"1"`（圈芒默认倍数，不是事件次数） | `"1"` |
| `mang_show_quan_amount` | string | 默认圈芒金额 = `mang_pi_score × 在座人数` | `"280"` |
| `mang_show_zou_count` | string | 当前链揍芒事件次数 | `"2"` |
| `mang_show_zou_amount` | string | 当前链揍芒本类型累计实际金额 | `"520"` |

皮池继续使用现有字段：

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `mang_pi_times` | string | 当前皮池金额（`GetAllMangPiTimes() + table_mang_times`） |

说明：

- 所有字段沿用当前消息的字符串数值格式，客户端按字符串转数字；
- `mang_show_state` 决定显示哪一行，**不要**再用三个 count 判断；
- 圈芒金额是服务端按 `mang_pi_score × 当前在座人数` 计算的默认值（如 40 × 7 = 280），随人数变化；
- 休芒/揍芒金额是**本类型累计实际扣款**，不是三类相加，也不是当前池；
- `mang_show_quan_count` 固定为 1，客户端显示 `x1` 即可；
- 老客户端忽略 `mang_show_state` 和新字段即可。

## 3. 客户端显示规则

### 3.1 按状态只显示一行

```text
state == 0：圈芒 x1 280     皮池 140
state == 1：休芒 x3 1360    皮池 4100
state == 2：揍芒 x2 520     皮池 140
```

- `state == 0`：显示圈芒，隐藏休芒、揍芒；
- `state == 1`：显示休芒，隐藏圈芒、揍芒；
- `state == 2`：显示揍芒，隐藏圈芒、休芒；
- 皮池 `mang_pi_times` 始终显示。

### 3.2 关键约束

- **不要**用三个 `if` 判断哪个 count 非 0；
- **不要**同时显示两行或三行；隐藏类型的计数/金额可能仍 >0，但当前状态不显示它，这是预期；
- 圈芒行固定 `x1`，金额直接用 `mang_show_quan_amount`，不要客户端按人数/底注反推；
- 休芒/揍芒行分别用 `mang_show_xiu_count/amount`、`mang_show_zou_count/amount`；
- 不能用旧字段 `xiu_mang_count`/`xiu_mang_times` 充当休芒行（它们是休+揍合并值，会把揍芒误显示成休芒）。

### 3.3 旧客户端

- 旧客户端仍读取 `xiu_mang_times`、`xiu_mang_count`、`mang_pi_times`，显示原来的合并芒果/皮池；
- 新字段是追加字段，旧客户端忽略即可；
- 新客户端不要同时显示旧的合并芒果行。

## 4. 状态与生命周期

| 状态 | 进入 | 显示 | 退出 |
| --- | --- | --- | --- |
| 0 圈芒 | 初始 / 普通手链重置 | 圈芒 x1 + 基础金额 | 荒→1；揍芒→2 |
| 1 休芒 | 最近一次事件是荒 | 休芒 xN + 本类型累计 | 揍芒→2；普通手→0 |
| 2 揍芒 | 最近一次事件是揍芒 | 揍芒 xN + 本类型累计 | 荒→1；普通手→0 |

- 最近一次事件覆盖状态；
- 切换时隐藏类型的本类型计数/金额保留，切回来继续用；
- 普通非荒、非揍手结束当前链时，state 回 0，休/揍计数金额清零；
- 圈芒基础金额按消息时在座人数计算，不累计；
- baseapp 重启后从 0 状态开始，不恢复。

## 5. 兼容性

1. 不新增消息、不新增命令、不新增路由；
2. 字段追加在现有 `当前_玩家_消息`，老客户端忽略；
3. 现有字段 `xiu_mang_times`、`xiu_mang_count`、`mang_pi_times` 语义不变；
4. 字段缺失时客户端按 0 处理；如果 `mang_show_state` 不存在，回退旧合并芒果行，不要只显示空白；
5. 不改结算、补芒账本、皮池分配和数据库；
6. 客户端不需要本地计算金额，直接展示服务端字段。
