# 俱乐部联盟模式 V2 — 客户端接口文档

> 版本：v2（2026-11-03）
> 对应服务端：`club_biaozhun.py` / `Hall.py` / `Account.py`，已部署测试服
> 设计说明见 `doc/俱乐部俱乐部联盟模式V2方案.md`

---

## 1. 概览

### 1.1 组织层级

```
平台(boss)
  └─ 联盟(总群主)            club_union_info
       └─ 俱乐部(盟主)        club_guuid_info.union_id / union_quota
            └─ 代理           club_agent_info（只有 percent，没有额度）
                 └─ 玩家
```

- **额度只在「总群主 ↔ 盟主俱乐部」之间存在**：`club_guuid_info.union_quota`（单位分）；
- 俱乐部内的代理和玩家全部走**积分**（`club_gold`），代理不再有独立额度账户；
- 抽水按 `percent` 逐层累加到代理的 **红利**（`club_agent_info.bonus`，单位分），可提取成积分。

## 2. 建联盟：`创建_联盟`

一个俱乐部创建者只能建一个联盟，创建后自动成为**总群主**并生成 6 位**联盟码**。

**请求**

```json
{"header":"创建_联盟", "club_id":"567671", "union_name":"XX联盟", "context":"ctx1"}
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `club_id` | 是 | 自己的俱乐部（必须是创建者本人） |
| `union_name` | 是 | 联盟名字，不能为空 |

**返回**：`GC_OK`

**推送 `ClubUnionCreate`**

```json
{"union_id": "123456"}
```

**校验顺序与失败文案**

| 顺序 | 校验 | 文案 |
| --- | --- | --- |
| 1 | 名字非空 | `联盟名字不能为空` |
| 2 | 俱乐部存在 | `俱乐部不存在` |
| 3 | 自己是创建者 | `只有俱乐部创建者可以创建联盟` |
| 4 | 自己的俱乐部还没联盟 | `你已经有联盟了，不能重复创建` |
| 5 | 自己账号还没建过联盟 | `你已经有联盟了，不能重复创建` |
| 6 | 联盟码生成成功 | `联盟号生成失败，请重试` |

**副作用**

- `club_union_info` 落一行，`union_quota = 0`；
- 自己的俱乐部自动绑定该联盟（`union_id` 写入），**额度从 0 开始**——必须先由平台注资、再由自己给自己授信，才能带入。

## 3. 我的联盟：`查询_我的_联盟`

总群主查看联盟信息、池余额、盟主列表。

**请求**

```json
{"header":"查询_我的_联盟", "context":"ctx2"}
```

**推送 `ClubMyUnion`**

```json
{"ClubMyUnion": {
  "union_id": "123456",
  "union_name": "XX联盟",
  "union_quota": "0",
  "members": [
    {"club_id": "567671", "club_name": "a", "owner_guuid": "718968", "owner_name": "abc", "union_quota": "0"},
    {"club_id": "535696", "club_name": "b", "owner_guuid": "580629", "owner_name": "def", "union_quota": "1000000"}
  ]
}}
```

| 字段 | 说明 |
| --- | --- |
| `union_quota` | 联盟池余额，**分** |
| `members` | 联盟内所有俱乐部（含总群主自己那家） |
| `members[].union_quota` | 该俱乐部当前可用额度，**分** |

**失败**：`你还没有联盟`

## 4. 申请加入：`申请_加入_联盟`

盟主用联盟码申请加入总群主的联盟。

**请求**

```json
{"header":"申请_加入_联盟", "club_id":"535696", "union_id":"123456", "context":"ctx3"}
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `club_id` | 是 | 自己的俱乐部 |
| `union_id` | 是 | 对方的 6 位联盟码 |

**返回**：`GC_OK`（无推送，等总群主审批）

**失败文案**

| 场景 | 文案 |
| --- | --- |
| 俱乐部不存在 | `俱乐部不存在` |
| 不是创建者 | `只有俱乐部创建者可以申请加入联盟` |
| 已有联盟 | `你的俱乐部已经有联盟了，不能重复加入` |
| 已有在审申请 | `已有申请在审核中，请等待总群主处理` |
| 联盟码不存在 | `联盟号不存在` |
| 申请自己的联盟 | `不能申请加入自己的联盟` |

> 申请只写 `union_apply`，**不会**立刻绑定；审批通过才写 `union_id`。

## 5. 审批

### 5.1 待审列表：`查询_联盟_加入申请`

**请求**

```json
{"header":"查询_联盟_加入申请", "context":"ctx4"}
```

（`union_id` 可不传，服务端按“自己是不是总群主”自动取）

**推送 `ClubUnionApply`**

```json
{"ClubUnionApply": [
  {"club_id":"535696","club_name":"b","owner_guuid":"580629","owner_name":"def"}
]}
```

**失败**：`你还没有联盟` / `只有总群主可以查看申请`

### 5.2 同意 / 拒绝

```json
{"header":"同意_加入_联盟", "club_id":"535696", "context":"ctx5"}
{"header":"拒绝_加入_联盟", "club_id":"535696", "context":"ctx6"}
```

| 项 | 说明 |
| --- | --- |
| 方向 | **由命令名决定**，不需要传 `agree`（老客户端传了也兼容） |
| 同意 | 对方俱乐部 `union_id` 写入、`union_apply` 清空 → 成为盟主 |
| 拒绝 | 只清 `union_apply`，对方可以再申请 |

**失败文案**

| 场景 | 文案 |
| --- | --- |
| 俱乐部不存在 | `俱乐部不存在` |
| 没有待审申请 | `该俱乐部没有待处理申请` |
| 不是总群主 | `只有总群主可以审批` |
| 对方已加入其它联盟 | `该俱乐部已加入其它联盟` |

## 6. 授信：`授信_联盟_额度`

总群主把自己的联盟额度分给盟主俱乐部。

**请求**

```json
{"header":"授信_联盟_额度", "club_id":"535696", "quota_fen":1000000, "context":"ctx7"}
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `club_id` | 是 | 目标俱乐部（**可以是自己**） |
| `quota_fen` | 是 | **分**，正数授出、负数收回；1 万元 = 1000000 |

**效果**

```
联盟池 −quota_fen
目标俱乐部 union_quota +quota_fen
```

两条流水都记 `opt_type='额度联盟授信'`：
- 联盟池那条：`user_guuid` = 总群主，`club_guuid` = 总群主自己的俱乐部；
- 俱乐部那条：`user_guuid` = 盟主，`club_guuid` = 目标俱乐部。

**失败文案**

| 场景 | 文案 |
| --- | --- |
| 自己没联盟 | `你还没有联盟` |
| 俱乐部不存在 | `俱乐部不存在` |
| 金额为 0 | `授信金额不能为 0` |
| 目标不在自己联盟 | `该俱乐部不在你的联盟里` |
| 联盟池不够 | `你的联盟额度不足` |
| 收回时对方余额不够 | `目标俱乐部额度不足，收回失败`（联盟池会自动回滚） |

> 收回时如果目标俱乐部额度不足，会整笔失败并回滚联盟池，不会出现“池扣了但俱乐部没退”。

## 7. 平台注资：`增加_联盟_额度`（仅 boss）

**请求**

```json
{"header":"增加_联盟_额度", "union_id":"123456", "quota_fen":10000000}
```

| 项 | 说明 |
| --- | --- |
| 权限 | 仅 `d_users.config["account"]["boss"]`，普通调用返回 `无权限` |
| 金额 | 只能正数，否则 `注资金额必须大于 0` |
| 流水 | `opt_type='额度联盟注资'`，记在总群主名下 |

**客户端不要做入口**，这是运营后台能力。

## 8. 查额度：`查询_联盟_额度`

**请求**

```json
{"header":"查询_联盟_额度", "context":"ctx8"}
```

不传参数，服务端按调用者身份返回，推送 **`ClubUnionQuota`**：

```json
{"union_id": "123456", "union_quota": "10000000", "is_owner": 1}   // 总群主：看联盟池
{"union_id": "123456", "union_quota": "1000000",  "is_owner": 0}   // 盟主：看自己俱乐部
```

| 字段 | 说明 |
| --- | --- |
| `union_quota` | 分 |
| `is_owner` | 1 = 看的是联盟池；0 = 自己俱乐部的额度 |

**失败**：`你还没有联盟`

## 9. 代理红利

抽水按 `percent` 逐层累加到 `club_agent_info.bonus`（**分**）。代理要用钱必须先提取成俱乐部积分。

### 9.1 查余额：`查询_俱乐部_红利`

**请求**

```json
{"header":"查询_俱乐部_红利", "club_id":"567671", "user_id":"", "context":"ctx9"}
```

| 字段 | 说明 |
| --- | --- |
| `user_id` | 留空 = 查自己；权限同积分流水（自己 / 群主 / boss / 代理查子树） |

**推送 `ClubBonus`**

```json
{"bonus_fen": "12345", "bonus": "123.45"}
```

`bonus_fen` 单位分，`bonus` 已换算成元。

### 9.2 明细：`查询_俱乐部_红利_明细`

**请求**

```json
{"header":"查询_俱乐部_红利_明细", "club_id":"567671", "count":20, "page":0}
```

**推送 `ClubBonusList`**

```json
{"ClubBonusList":[
  {"number":"0","count":"12","date":"2026-11-03 10:12:33",
   "guuid":"580629","name":"a3","bonus":"83","level":"club2","room_id":"772975"}
]}
```

| 字段 | 说明 |
| --- | --- |
| `bonus` | 本局分到的红利，**分** |
| `level` | 分成层级：`clubroot` = 创建者，`club2`/`club3`… = 第几层代理 |
| `room_id` | 哪一局 |

**权限**：群主看全俱乐部各级分成；其他代理只看自己那部分。

### 9.3 提取：`提取_俱乐部_红利`

**请求**

```json
{"header":"提取_俱乐部_红利", "club_id":"567671", "extract_gold":10, "context":"ctx10"}
```

| 字段 | 说明 |
| --- | --- |
| `extract_gold` | **单位元**，必须是 **≥1 的整数** |

**效果**

```
bonus   − extract_gold * 100   （分）
club_gold + extract_gold        （元）
写一条 club_history_info：opt_type='红利提取'，user_gold=+extract_gold
```

**失败文案**

| 场景 | 文案 |
| --- | --- |
| 不在俱乐部 | `你不在该俱乐部` |
| 传小数 | `提取金额必须是整数元` |
| 小于 1 元 | `每次至少提取 1 元` |
| 余额不足 | `红利不足，当前可提 X 元` |

> **不足 1 元的部分永远留在 `bonus` 里**，不支持提取；抽水按比例算下来会产生零头，属于正常现象。

## 10. 创建俱乐部收费

`创建_俱乐部` 现在扣 `d_halls.create_club_stone`（默认 **10000 钻**）。

**请求**（不变）

```json
{"header":"创建_俱乐部", "club_name":"xx", "club_mode":"1", "club_prop":""}
```

| 场景 | 结果 |
| --- | --- |
| 钻石不足 | `钻石不足，无法创建俱乐部` |
| 创建失败（取号 / 落库失败） | 自动退回，流水 `创建俱乐部-退回` |
| boss 账号 | 不扣 |

## 11. 带入规则变化（重要）

带入不再扣「最近已授信代理」的额度，改扣**俱乐部额度**。

| 场景 | 结果 |
| --- | --- |
| 俱乐部未加入联盟 | 额度恒为 0，带入被拒；服务端日志记「俱乐部未加入联盟」，与「额度不足」分开 |
| 俱乐部额度 < 本次带入 | 拒绝，玩家积分不动 |
| 结算 | 回补到**同一个**俱乐部额度池 |
| 审批带入的“管理员追加”部分 | 从俱乐部额度扣，结算时不回补（与改动前一致） |
| 抽水 | **不再回补额度**，全部进代理红利 |

**代理上分**：仍不扣代理自己的积分（钱在玩家带入时从俱乐部额度出）；**非代理上分**：扣自己积分，流水记 `积分赠送` / `积分受赠` 两条。

**玩家间赠送**：俱乐部内不再限制授信代理一致（额度统一后同俱乐部即同账户），`CanGiveClubGold` 恒放行，只校验双方都在俱乐部。

## 14. 错误文案总表

| 文案 | 场景 |
| --- | --- |
| `联盟名字不能为空` | `创建_联盟` 名字空 |
| `只有俱乐部创建者可以创建联盟` | 非创建者建联盟 |
| `你已经有联盟了，不能重复创建` | 重复建 / 俱乐部已有联盟 |
| `联盟号生成失败，请重试` | 6 位码连续冲突 |
| `只有俱乐部创建者可以申请加入联盟` | 非创建者申请 |
| `你的俱乐部已经有联盟了，不能重复加入` | 已入盟还申请 |
| `已有申请在审核中，请等待总群主处理` | 重复申请 |
| `联盟号不存在` | 联盟码错误 |
| `不能申请加入自己的联盟` | 申请自己的联盟 |
| `你还没有联盟` | 总群主/盟主查询类命令 |
| `只有总群主可以查看申请` | 非总群主看待审 |
| `该俱乐部没有待处理申请` | 审批一个没申请过的俱乐部 |
| `只有总群主可以审批` | 非总群主审批 |
| `该俱乐部已加入其它联盟` | 审批时对方已入盟 |
| `该俱乐部不在你的联盟里` | 授信给别的联盟的俱乐部 |
| `授信金额不能为 0` | `quota_fen = 0` |
| `你的联盟额度不足` | 联盟池不够 |
| `目标俱乐部额度不足，收回失败` | 负数授信但对方余额不够 |
| `无权限` | 非 boss 调 `增加_联盟_额度` |
| `注资金额必须大于 0` | 注资传 0 或负数 |
| `你不在该俱乐部` | 提取红利但不在代理树 |
