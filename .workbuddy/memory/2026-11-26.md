## 切换会话强制落底（16:05，两台前端）
- 现象：左侧点开新会话，右侧消息列表停在顶部（不自动到底）。
- 根因：换会话时列表先空/先旧后被替换，浏览器把 scrollTop 夹回 0 并触发 scroll 事件，
  `handleMessageScroll` 在"新高列表 + scrollTop≈0"上算出「不贴底」→ stick=false，
  之后消息到达时 `if (!stickToBottom.current) return` 直接跳过滚动，表现为停在顶部。
- 修法：切会话时置 `scrollLockUntil = now+600ms`，窗口内不按滚动位置改判 stick；
  同时立即跳一次 + 80/240/520ms 再补跳三次（等异步消息与历史图片撑高），最后停在底部。
- 发布：两台 web `index-3clyucvg.js`，回滚 `web.previous-scrolljump-<ts>`。
