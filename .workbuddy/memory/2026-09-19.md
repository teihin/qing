**为什么结算才响**：结算阶段 `account.roomID` 已不再是有效房号。本项目自己的记录：
- commit `436d2a3` 说明："避免结算阶段 account.roomID 被清空后丢失参考房间"；
- `panelGameView.ts` 3222 / 3269 注释、`QueueMatchManager.ts` 91、`panelRecordInfo.ts` 73 均提到"结算阶段被清空"；

清空动作**不在客户端**（客户端只在退房回包 `panelGameView` 1559/1541、退出房间按钮 728、结算超时 3345、
俱乐部关闭 `DrhLogicMgr` 475、GPS 拦截 2595 时清）→ 是服务端在结算时改写该属性。
`DrhLogicMgr:574` 用 `strRoomID == "0"` 判断同一状态，说明该值很可能是**数字 0**（字符串 "0" 与 "" 弱相等为假，也就不会响）。

房间内是真房号 → `roomID == ""` 为假 → 不响；结算期为 `""` 或数字 `0` → 与空房间字段弱相等命中。

## 排查+修复：浏览器版 `getAccount().guuid` 未判空导致断线期间每 0.1s 抛异常

主人给的浏览器控制台截图里有两组错：① `WebSocket connection to 'wss://154-37-155-17.nip.io/ws/20013/' failed`
+ `onerror_before_onopen`；② `DrhPlayerLogic.ts:2254 Cannot read properties of undefined (reading 'guuid')`。

**① WSS 连不上 = 网络/服务端侧，不是代码。** 本机实测（13:39，node 22 全局 WebSocket）连
`wss://154-37-155-17.nip.io/ws/20013/` **3/3 全部 101 成功且服务端不主动断开** → 服务器与反代当时是通的。
探测口径：`GET /ws/20013/`（不带 upgrade）返回 **502**=反代后端不通、**404**=端口不在白名单（实测 `/ws/9999/` 404）。
注意本机 DNS 被本地代理 hijack 成 fake-IP（`154-37-155-17.nip.io → 198.18.0.65`），curl 走本机 HTTP 代理、node 直连，两条路都能通。

**② guuid 报错 = 真 bug，已修。** 链路：`reset()` 会置 `entity_id=0` + `entities={}`（kbengine.js 3122/3148/3158），
所以 `KBEngine.app.player()`（=3215）在**断线重连期间必返回 undefined** → `GameDataManager.getAccount()` 返回 undefined。
`TryRecoverMissingSelfActionUI` 第 2254 行原先直接 `.guuid` 未判空；异常发生在 `strCurCountDown` 自减**之前**，
所以倒计时永不归零 → 计时器永不 unschedule → 断线期间**每 0.1s 无限抛异常**（自愈要等重连成功）。
- 改法（`assets/scripts/logic/DrhPlayerLogic.ts`，+4/-1）：先取 `accountSelf = GameDataManager.getAccount()`，
  再用 `accountSelf == null || this.info.strUserID != accountSelf.guuid` 短路。
- 验证：typescript@5.6.3 `createSourceFile` 语法诊断 **HEAD 版与工作区版均为 0**；`git diff --check` 通过；影响面只此一处。
- 同文件另有 ~12 处 `getAccount().guuid` 未判空（214/246/700/738/920/1063/1175/1237/1539/3011/3133/3445），
