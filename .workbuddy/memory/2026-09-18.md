### 关键结论（重要）
- **单纯图生图改不了「效果不变」**：Seedream 4.5 会把整只盾牌重画——轮廓、金边层数、蓝菱格尺寸、底部黑桃变黑。
  试了 7 版提示词（含透明底输入、显式保真清单、局部重绘框架），最好的一版（gen_D）轮廓接近但仍是重绘。
- **Ark 生图 API 无 mask/inpaint 参数**，做不到真正的局部重绘。
- 因此改用**像素级合成**：原图当底，只重建文字区背景 + 贴新字形，其余像素（盾牌、金边、材质、透明通道）原样不动。
- 产物：`art_sources/rename-BY/compose/login_shield_exact_BY.png`（417×514 RGBA，可直接覆盖原文件，`.meta`/UUID 不变）。

### 踩过的坑（复用要点）
1. **4.5 的 size 下限不是 1280×720**，实测报错要求 ≥ 3,686,400 px。显式像素尺寸要按这个来（本次用 2048×2524）。
2. `np.nonzero` 按行序返回，`a[0]`/`a[-1]` **不是 min/max**，取包围盒必须用 `.min()/.max()`——曾因此把字形切片切空。
3. 旧文字周围有暗色投影，归一化卷积填背景时会从「暗环」插值导致整块发黑；改用**离掩码 ≥14px 的远场做三次多项式曲面拟合外推**才干净。
4. 大 sigma 的归一化卷积会把远处金色边框颜色拉进来，得到灰褐色，务必限制采样范围。
5. 蓝底是**不规则有机纹理**（不是规则菱格），无法平铺，用「干净区频谱 + 随机相位」合成高频纹理。

## ImagesLuck/公告/1.png —— 8 个标题提亮（初版记录，已作废）

  故改为**对原有文字像素做提亮**——alpha 通道一字节不改，字形绝对不变。
- **原图文字结构（剖面实测）**：描边 `(193,218,232)` 每笔画各一圈、约 2px；
  字身 `(25,100,138)` 不透明；面板底 `(17,25,57)`，alpha 在 60–160 之间且**横向变化剧烈**。
  看不清的根因：字身明度（L≈82）与深蓝底（L≈29）差太小，只剩描边能辨认。

  3. 按亮度锚点曲线提亮：`(39→98) (82→164) (150→226) (200→255)`，

  4. **必须再用用户圈定的标题矩形做硬掩码**：面板顶部有一条白色卡边（`246,246,246` 不透明），
     alpha 与字形无法区分，不裁会把卡边也提亮。
  5. 6bit 量化 + `optimize=True, compress_level=9` → **727,882 字节（−22.8%，比原图还小）**。

### 坑（都很值钱）
1. **提示词里描述原图内容时，必须是「亲眼看过原图的」描述。**
   我在公告面板提示词里写了「保留底部导航条『公告 客服 钱包 我的』」——那是 `announcement_menu_long_exact`

   AI 老老实实**凭空补了一条导航栏**。→ 写保留清单前逐张看图，不要凭印象复制。
2. **`post.py` 取包围盒时，原图与生成图必须用同一个 alpha 阈值。**
   原先给原图用 `8/255`（含外发光）、生成图用 `0.35`（不含），结果生成内容被拉伸去填原图的光晕包围盒，
   **整只盾牌被放大**。改成两边都用 `0.5`。→ 任何 bbox 对齐，先检查两个阈值是不是同一个。
3. **AI 会偷偷加一圈淡光晕。** 22 张里 10 张的 `alpha>0` 覆盖率比原图高一大截
   （例：`shield_hd` 0.610→0.848）。修法：按原图覆盖率为目标，对生成 alpha 做阈值拟合
   `al = clip((al-t)/(1-t),0,1)`，二分求 t，**这一步同时把体积又降了一档**（`shield_hd` 1901→1120 KB）。
   → 阈值拟合要设上限：若拟合后覆盖率反低于原图，说明原图的光晕是**设计的一部分**，不能压。
4. **原图是扁平矢量图时，AI 重绘后 PNG 会暴涨。** `bigbig.png` 水平相邻像素相同率：原 0.856 → 生成 0.501；
   于是 44 KB → 112 KB。它是扁平色块图，AI 给它加了微纹理。

   另一张 `牌背3` 同因 41→129 KB，同法 → 52 KB。
   → 判据就是「水平平坦度」，一测就知道是不是这类图。
5. **只贴 bbox 内的内容会裁掉光晕。** `秦_发现按钮` 原图的光晕有 14.5% 落在自己 bbox@0.5 之外。
   修法（`fix3.py`）：按 bbox@0.5 求非均匀缩放比，把**整张**生成图缩放后按偏移贴上去。
   附带的坑：贴图宽度要用**源图**宽 `gen.shape[1]`，我一开始写成目标宽 `W`，贴出来只有 17px。
6. **`xargs -a` 在 macOS 上不存在**；**并行写同一个重定向文件会把行写花**（老坑，又踩一次）。

### 新技术：「清除封闭的大块白色」（这次新增，很重要）
`post.py` 的抠白是**从画面四边连通**才开始抠（`flood` 种子只取边界）。
**被金框封闭的白色区域（盾牌菱形内部）永远抠不到**，会以 ~40% alpha 残留成奶白块。
补丁（`kill_big_white`）：
1. `soft = clip((mn-190)/50) * clip(1-(mx-mn)/40)` → 白色可能性；
2. `core = soft > 0.45`，用 `MinFilter(2k+1)`（k=5）**腐蚀**——字母上的小块白消失，
   菱形大白块存活 → 当种子；
3. 在 `core` 内**测地重建**（迭代膨胀 ∩ core）→ 再 `dilate(2) & (soft>0.30)`；
4. `al *= (1-grow)`。
k=5 时 R1 干净；**k 太大会把字母掏空**（R2/R3 被掏空成空心字，作废）。
