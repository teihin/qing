## 防盗号：服务端上线说明的复核结论（只读，未动代码）

  `:3561` 收并填 `serverErrs`）。`GameDataManager.isAntiTheftLoginError` 按**名字**匹配
  （`ANTI_THEFT_DEVICE_REQUIRED/INVALID/MISMATCH/VERIFY_UNAVAILABLE`）。
  → 只要服务端把这 4 个码登记进下发的错误描述表，客户端**不用发版**就能出正确文案；
  只返回裸数字则落到 `hasServerErrorDefinition` 为 false 的分支（`GameDataManager.ts:247-255`）：

- 「老客户端发 datas=登陆」的归因不准：`DeviceIdentityManager.createLoginData()` 在
  `available=false` 时**任何版本**都返回 `"登陆"` → 机型取不到 ID 也会撞 0xA01，风险面比老版本大。
- 设备 ID 稳定性（决定误伤率）：Android 用 `ANDROID_ID`（Android 8+ 按**应用签名**作用域 →
  换签名/包名会全量漂移，等于所有开防盗号的号一起锁）；iOS 用 Keychain
  `AccessibleAfterFirstUnlockThisDeviceOnly`（重装保留、**换机不跟随**）；Web 靠 IndexedDB+localStorage
  （清缓存/换浏览器即变，误伤率最高）。
- 服务端说明里**没提**的两项我们文档硬要求：DB/校验异常必须 fail-closed

## 20:2x-20:4x 安卓键盘：原生输入条紧贴键盘上沿（真机已验证）

- 修法：① 容器改 `FrameLayout.LayoutParams` + `gravity=BOTTOM`；② 位置改 `bottomMargin = 键盘高度`（`WindowInsets.Type.ime()` 优先 → `getSystemWindowInsetBottom()` → `rootH - visibleFrame.bottom`），每次 insets/布局变化重算，不再一次性锁存；③ 删 `setFitsSystemWindows(true)`（吃底部 inset 垫出空隙）与废弃的 `getDefaultDisplay().getHeight()`。
- 文件在 Creator 安装目录（`settings.gradle` 的 `libcocos2dx` 直接引用），**不在本仓库、重装 Creator 会被覆盖**。已落 `tools/apply_editbox_ime_patch.py`（幂等 + 自动备份 + `--check`）与模板 `tools/android-engine/Cocos2dxEditBox.java`。
