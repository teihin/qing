# 改动整理：2026-11-11 06:00 → 11-12

分支 `codex/club-ui`。按功能归类，仅列主要项。

## 游戏内

1. 开房「暗抽」改为后台按俱乐部 / 联盟授权，未授权的俱乐部不再显示暗抽设置。
2. 未授权时创建规则自动按 0 暗抽，规则列表和删除提示也不显示暗抽，不留空档。
3. 关闭暗抽后创建规则弹窗自动收紧排版，按钮和说明重新居中。
4. 消息页新增「BF 聊天」显示开关，仅俱乐部创建者可操作。
5. 关闭后本俱乐部所有代理和玩家都看不到置顶官方客服入口，创建者自己也隐藏。
6. 「我的红利」新增「业绩股」页签，可输入下级代理 ID 添加业绩股成员。
7. 业绩股列表显示成员头像、昵称、ID 和昨日占比，底部显示「我的 / 已下放 / 剩余」比例。
8. 牌桌带入积分弹窗按新视觉重做：深蓝发光面板、干净标题、放大居中的当前带入数字。
9. 带入弹窗新增最低 / 最高固定列、四处美术字标签和参考图风格按钮。
10. 带入弹窗实时显示按比例扣除的钻石和钻石余额，关闭带入钻石时自动隐藏。
11. 玩家信息统计区改为两排三列蓝色卡片，名称在上数字在下，更易读。
12. 统计项「失败率」改为「摊牌率」。

## 运营后台

13. 俱乐部管理、联盟管理新增「暗抽」列和「暗抽设置」入口。
14. 已入盟俱乐部的暗抽跟随联盟开关，不能在俱乐部单独修改，避免口径冲突。
15. 暗抽开关需二次确认并填写原因，操作全程留审计记录。
16. 业绩奖励 / 核心奖励 / 奖池共享三类奖励统一按业绩股净次数比例分摊。
17. 「核心奖励」不再按上次金额分摊，自动分摊按钮改为「按业绩比例分摊」。
18. 业绩发放页默认日期改为昨天，选今天会提示业绩尚未结算。
19. 发放表格改为「业绩(毛次) / 净业绩(次) / 业绩占比」，去掉整条线输赢列。
20. 奖池共享查历史日期时优先使用当天保存的奖池快照，避免用今天的数据算历史账。
21. 玩家管理 BOSS 号整行标红，条件查询新增「BOSS号」筛选。
