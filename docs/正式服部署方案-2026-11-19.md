## 3. 必须改代码的地方（3 处）

### 3.1 XuanManager：数据库主机白名单

`XuanManager/server/internal/config/config.go:108` 和 `:117`

```go
if cfg.DBHost != "127.0.0.1" && cfg.DBHost != "localhost" {
    return Config{}, fmt.Errorf("XUAN_DB_HOST 只允许 127.0.0.1 或 localhost")
}
```

`XUAN_GAME_DB_HOST` 同上。**不改就起不来**，因为正式服库在 172.22.161.126。

改法（推荐）：新增 `XUAN_DB_ALLOW_REMOTE=true` 显式开关，开关打开时允许私有网段地址；
开关关闭时维持现有 127.0.0.1 限制。避免把「只允许本机」这条安全基线悄悄放开。

### 3.2 ChatTool：同一处限制

`ChatTool/server/internal/config/config.go:171` 和 `:180`，`CHAT_DB_HOST` / `CHAT_GAME_DB_HOST`。
改法与 3.1 一致（共用同一开关语义）。

`CHAT_XUAN_MANAGER_URL`（`:219`）仍是本机 8891，**不用改**。

### 4.3 客户端地址来源的关键决策

`SERVER_IP` 现在走 CDN 域名（实测 220.185.184.144 等节点回源到测试服 20013）。两条路：

- **A（推荐）**：正式服继续用这个 CDN 域名，在 CDN 控制台把回源改成 `8.153.70.197`；
  测试服另配一个域名或直接 IP。好处是客户端 `SERVER_IP` 不用动，坏处是动 CDN 会影响现有玩家。
- **B**：正式服直接用 `8.153.70.197:20013` 直连，客户端按 `BUILD_ENV='prod'` 出独立包。
  不动 CDN、不影响测试服，代价是裸 IP 无加速。

需要你定。**在定之前，客户端那部分我不动。**
