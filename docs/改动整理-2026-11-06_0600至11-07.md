# 2026-11-06 ~ 2026-11-07 功能更新

## 账号与登录
- 退出登录、切换账号后保留已填写的账号，只需重新输入密码。
- 重置密码弹窗的提示文字改为输入框占位提示，开始输入后自动消失；修正底部安全提示文案。
- 被踢下线提示区分两种情况：「账号在其他设备登录」与「服务器维护/重启」。

## 我的 / 个人中心
- 个人中心各入口按钮的图标位置、文字对齐和字重统一；「上下分记录」更名为「上下记录」；兑换钻石图标重新设计。
- 新增「额度授权记录」入口和弹窗：查看大盟主给各盟主的授信、收回额度流水，支持分页。
- 合伙人（代理）在俱乐部卡片中也能看到「我的红利」入口。

## 俱乐部 / 数据统计
- BOSS 账号在「我的」页新增「数据统计」入口。
- 数据统计面板包含三个页签：玩家信息、代理链、分组管理。
- 玩家信息、代理链列表行展示：身份、所属俱乐部、积分、比例/暗扣，以及今日/昨日/累计的输赢、贡献、红利。
- 行内提供操作按钮：查看、代理链、战绩、添加到分组。
- 新增「玩家战绩」页面：查看指定玩家的历史战绩，支持今日/昨日/前天切换和分页。
- 从数据统计中查看历史牌局详情，返回时不再退出当前房间。
- 分组管理：查看分组列表、新建分组、按玩家 ID 加人、查看组内成员、移出成员、删除分组。
- 俱乐部成员资料弹窗统一改为只读展示。

## 牌桌 / 游戏内
- 牌桌点击玩家头像：BOSS 账号打开「数据统计」，普通账号仍打开玩家资料。
- 赢家留座：局中提示「留座限时 3 分钟」。
- 退出房间：局中可预约退房，当前牌局结束后自动退出。
- 桌布调整：删除第 5 张绿色桌布，深蓝桌布排到第 1 并设为默认。
- 游戏内红色筹码的「BY」改为「BF」。
- 奖池牌型列表第 5 档文案改为「丁皇」。

## 聊天 / 消息
- 消息页置顶客服行只显示「BF」，不再显示「官方客服」和「置顶」。
- 默认对话只保留 BF 客服、盟主（未入盟显示群主）、大盟主，不再显示其他层级上级代理。
- 「清除聊天」按钮在手机端显示错误的问题已修正。
- 客服工作台「聊天托管」新增：会话备注、置顶（支持分组/账号/单会话三级）、快捷话术、删除单条会话。
- 提示弹窗层级修正，不再被数据统计、战绩等页面遮挡。

## 记录与金额显示
- 金额颜色统一为客户口径：红色代表加分，绿色代表减分。
- 赠送记录页标题改为「赠送记录」，正数金额补充「+」号并按红绿显示。

## 运营后台
- 俱乐部管理列表新增「俱乐部总积分」列。
- 玩家管理新增「用户密码」列：显示玩家登录密码明文，仅管理员可见；未收录密码的账号显示「未收录」。
