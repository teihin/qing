## 后台

页面入口：游戏管理 → 奖池业绩，路由 `/game/jackpot`。

| 后台接口 | 权限 | 用途 |
| --- | --- | --- |
| `GET /api/game/jackpot/agents` | `game.jackpot.view` | 空 ID 分页列出已开通玩家；`playerId` 精确查询任意玩家当前状态 |
| `PUT /api/game/jackpot/agents/{playerId}` | `game.jackpot.configure` | 请求体 `{enabled: boolean, expected: boolean}`，校验原状态，经游戏服务设置、数据库回读确认并审计 |
| `GET /api/game/jackpot/report?date=YYYY-MM-DD` | `game.jackpot.view` | 默认北京时间昨天，调用游戏服务结算命令，兼容字符串/对象两种返回包裹 |

- 配置只写 `client_prop`，严格使用 `True` / 空串；不直接修改游戏数据库。
- `512`、`1280` 都必须回读到目标状态才能显示配置成功；未确认提示刷新核对。
- 结算页显示提留总额、应返款合计、平台保留、对账结果、代理毛/下发/净业绩、占比、返款及下发名单。支持筛选、分页和 CSV 导出；昵称等文本做表格公式转义。
- 新增迁移 `XuanManager/server/migrations/027_jackpot_performance.sql` 注册菜单和查询/配置权限，默认仅赋予原有超管角色，可按需分配给财务。该迁移不修改玩家开通状态，不建游戏业务表。
- 本期按请求实现配置和查询及导出；未实现可选的线下付款登记账本，也不会自动返款。
