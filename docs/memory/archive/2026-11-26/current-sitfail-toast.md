## 2026-11-26 「带入失败，请检查俱乐部额度或积分」的真实出处

- 该弹窗来自 `panelGameView.onRoomCommand`：`param` 含 **`预坐_事件`** 且 `nCode != 0x200` 时弹出，
  文案写死为「带入失败，请检查俱乐部额度或积分」（非俱乐部房则「占座失败，请重新选择座位！」）。
  **所以这条提示的真实含义是「预坐失败」，跟带入金额/积分无关。**
- 与之配套：`坐下_事件` 回包非 0x200 也是失败（截图为 `onRoomCommand301坐下_事件1`），成功是 `200/0x200`。
- 我方漏洞：预坐回包实际走 **`onGameCommand`（不是 onRoomCommand）**，我们只处理了「执行检查_命令」，
  其余一律 return → 状态机以为预坐没确认。已补：`onGameCommand` 里 `param` 含「预坐」时按 200/0x200/512 判成功，
  设 `presitOk` 并清 `badSeats`，失败则记 warn 并回抢座。
- 账号俱乐部积分实测：worker001=441 / 002=922 / 003=9295 / 004=10031（都 > 100），
  进一步证明 769 不是积分不足。
