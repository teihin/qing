## 2026-11-26 「轮到我却不出牌」主因：别人的排队消息把出牌定时器取消

- 原始时序（worker001 12:31:56）：
  `.809 当前_玩家_消息 st=东家_决策_第一次_下注_状态 act=True`（轮到我，排出牌定时器）
  `.810 当前_玩家_消息 st=旁家_排队_第一次_下注_状态 act=False`（**别人的消息**）
  → 旧代码在「状态不含『决策』」时无条件 `cancelAction()`，把刚排的定时器清掉 → 一秒内静默放弃。
- 修：`!isDecisionState` 时只有 `mine`（这条消息说的是我）才取消；别人的消息不动我的定时器。
- 顺带放宽定时器守卫：不再因 `seated=false` 退出（服务端 `is_action=True` 就说明我在座），
  改为检查 `stage==='room'`，并给每种跳过原因补 debug 日志。
- 这一条同时解释了「看牌后、第二圈、结算前」等大量「轮到我但没动作」的情况。
- 同一轮再收口两处「别人的消息影响自己」：
  1. 别人的 `决策_倒计时_消息` 以前会 `cancelAction()`，等于我刚排出牌就被别人的广播清掉 → 已删，
     非本人消息直接 `return`（与真实客户端「只有 PlayerPos.self 才更新」一致）；
  2. `onServerPlay` 开头 `if (!state.seated) return` 会把「轮到我」一起丢掉（预坐留座期间 seated 仍可能是 false）
     → 已删，是否动作只由 `mine` 判断。
- 需重启 worker。
