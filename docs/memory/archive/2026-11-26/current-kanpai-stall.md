## 2026-11-26 看牌阶段卡住 / 无动作兜底

- 报文证据：第四张牌后是 `state=旁家_决策_看牌_状态`、`role=看牌`、`is_action=True` —— 这是「要不要看牌」的决策窗口，
  不是下注；机器人的角色解析里没有「看牌」，策略给不出动作 → 该窗口空转，倒计时走完。
- 改（`client.js`）：
  1. `当前_玩家_消息.state` 存进 `state.stateText`；命中「看牌」窗口时发 **`玩家_搓牌_事件`**
     （对照真实客户端 `panelGameView` 的「看牌」按钮，之前误用 `reqPass` 已纠正）；
  2. `submitAction` 里「策略无可用动作」原来只在扯牌阶段才发，现在**非扯牌阶段降级为过牌**并记一条 warn，
     避免任何窗口静默空转到超时。
