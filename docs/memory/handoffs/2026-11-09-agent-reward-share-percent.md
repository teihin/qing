# 业绩核心共享：三栏常驻今日业绩占比（未部署）

日期：2026-11-09　分支：`codex/club-ui`（未提交）　部署：未部署

## 目标

用户在「业绩核心共享」页面提出：业绩奖励 / 核心奖励 / 奖池共享三个分栏，不管切到哪一栏，
顶部都显示所有已加入代理的今日业绩占比，合计统一为 100%；每行也要显示自己的占比，
并且跟随游戏实时业绩变化，方便发放时一眼看清每个人的占比。

**口径已由用户确认：沿用当前后台净点数**（俱乐部整条线今日贡献，扣掉直接下级后的净点数），
不切换到 APP「业绩比例」的奖池提留数据。占比 = 本人净点数 ÷ 本次名单净点数合计 × 100%。

## 关键实现

- **合计固定 100.00%**：`rewardSharePercents` 把净点数换算成万分位整数（百分比 ×100），
  按最大余数法补尾差，保证只要有正权重，所有行四舍五入后合计恰好 100.00，
  且同输入结果稳定。零/负权重行固定 0.00%。
- **和分摊一致**：占比权重直接取 `perf.Net`，与「业绩奖励」自动分摊使用同一份权重；
  名单内被排除的人不参与分母。
- **三栏都显示**：概览接口本来三栏都会计算 `perf`，这次在同一处补 `sharePercent`，
  所以切到核心奖励 / 奖池共享时顶部和行内占比不变（仍按当前分栏的参与名单归一）。
- **实时同步**：前端每 30 秒静默重拉一次概览，只合并 `perf / line / sharePercent / totals.points`，
  不覆盖客服正在填的金额、计划总额和主子账号拆分；页面切到后台标签时暂停。
  顶部显示「最近同步 HH:mm:ss」，并提供「刷新业绩 / 立即同步」手动入口。
- **0 业绩**：当日净点数全为 0 时顶部显示提示，不伪造 100%；有正业绩后自动恢复。
