# 2026-11-05 玩家设置：下级暗扣比例

- 目录/分支：`/Volumes/SSD/qing`，`codex/club-ui`
- 目标：联盟大盟主、或未加入联盟的俱乐部创建者，在成员列表点开自己的下级时，可设置该下级的暗扣比例。

## 改动

- `assets/scripts/UI/ClubManagementView.ts`
  - 玩家设置「成员设置」页签、代理行下方新增「暗扣」行；左侧文字「暗扣」，右侧「调整」按钮，点击复用 `玩家设置输入弹窗`。
  - 显示条件：目标是自己的下级且身份不是普通玩家（`isDarkTarget`：大盟主/盟主/群主/管理员/合伙人）；当前是第一层（非跨级只读）、不是本人/创建者。操作者是联盟总群主（`canReviewUnion`）或未入盟俱乐部创建者（`unionKnown && !hasUnion`）。
  - 输入 0-20 整数，0=不扣；发送 `设置_俱乐部_代理_暗抽`，成功/失败按最终 `0x200`/`0x301` 显示服务端文案。
  - 盟主行属于另一家俱乐部：`club_id` 取目标行自己的 `club_id`（缺失时用联盟成员缓存），定位不到就提示刷新，不回退当前俱乐部。
  - 服务端暂无「查询某个下级当前暗扣值」接口，弹窗不展示历史值，只做设置。
- `assets/scripts/UI/ClubManagementApi.ts`
  - `ClubAction` 增加 `setAgentDark`，命令映射 `设置_俱乐部_代理_暗抽`，请求字段 `club_id + user_id + dark_percent`。
- `assets/resources/UI/panelMain.prefab`
  - 玩家设置面板新增默认隐藏的 `暗扣底`（620×64）、`暗扣`（150×38）、`玩家设置调整暗扣`（88×44，文字「调整」），均位于 y=-240，复用比例行底板与调整按钮美术。

## 接口口径

- `设置_俱乐部_代理_暗抽`：`{"header":"设置_俱乐部_代理_暗抽","club_id":"...","user_id":"...","dark_percent":2}`。
- `dark_percent` 为 0-20 的整数；服务端另有 `-1` = 清空并回退房间默认，本期未做入口。
- 同一玩家在多个俱乐部当代理时按 `club_id` 隔离；只影响后续结算，已结算牌局不追溯。
- 服务端文档 `服务器文档整理/俱乐部暗抽-客户端接口文档.md` 标注「服务端本地已实施，未部署」，当前正式服可能返回失败；文档同时仍写「目标必须是本俱乐部 used 代理」「不允许设置创建者/盟主自己的暗抽」。本期按产品要求把盟主行也接到同一命令，盟主是否可设取决于服务端是否放开，失败时直接显示服务端错误。
