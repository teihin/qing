**抠底必须让 AI 别画纯白高光**（2026-11-16 踩过）：
- 第一版提示词要求「白色高光亮边」，结果笔画上的纯白与白底同色，抠底只能按连通性区分 → 字内封闭空隙留白块；
- 在成品上按颜色补抠（`mn>=248 & sat<10`）会把笔画高光一起挖掉，字面变麻点；
- 正确做法：提示词明确「高光用浅米金色，画面除背景外不要出现纯白」，抠底判据才可能干净。
- **判背景必须用「与纯白的 RGB 色距」，不能用亮度/min 通道**（第二次踩坑）：用 `(mn>=240)&(sat<=16)` 这类亮度判据时，字顶的浅米金高光（mn≈245）会被当成背景抠掉，三张字全部被水平切头。色距 `d = ‖255-rgb‖` 下浅金高光 d≈27、纯白 d≈0，一刀就能分开。
- 最终抠底：`alpha = clip((d-8)/16)` → 与画面边界连通的低 alpha 区域清零（去背景雾气）→ 0.5px 高斯 → 色溢填充 → bbox 对齐皮池墨迹区（95×44，居中 y=8）→ 预乘缩放 → 6bit 量化。三张 9.0/9.0/9.7KB 均小于皮池 10.4KB；成品内容行 8–51、列 3–96，顶部无平切。
