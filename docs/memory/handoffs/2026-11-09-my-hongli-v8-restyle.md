# 我的红利：金框美术 + 金色美术字（俱乐部/联盟双面板）

更新：2026-11-09。分支 `codex/club-ui`，检出 `/Volumes/SSD/qing`。

## 目标与范围

用户反馈「我的收益里的数字和文字不好看」，给了竞品截图（金框 + 桂冠 + 金币/礼盒 + 金色数字）。要求：只把金额类数字和部分文字换成美术字，界面美术升级，但保持自己的深蓝 + 香槟金色调，不照抄竞品的亮青蓝。

范围：`panelMyHongli.prefab`（俱乐部分红）与 `panelUnionHongli.prefab`（联盟分红，结构完全相同）。

## 视觉口径（用户选定 B3 金框定稿版）

- 深蓝玻璃底板 + 金色双线描边 + 内高光；列表外框用 9 宫格，四角金色弧线角花。
- 顶部「我的红利」改用与「我的业绩/排行榜」一致的浅米白横向美术字、细深蓝描边和金色下沿。
- 今日/昨日/累计三栏：暖金标题 + 桂冠夹住的金属数字。
- 未领取行：青蓝渐变胶囊底，左侧状态区、右侧金额槽和金色分隔线；金币图标 + 浅色「未领取红利」美术字 + 金色数字；右侧金色按钮「提取红利」带礼盒图标。
- 表头、行分隔线改金色细线；列表行仍是暖白正文，只有「金额」列用美术字。

## 首轮机内反馈与第二轮修正

用户真机截图暴露三处问题，已重做：

1. 「未领取红利」「提取红利」美术字完全不显示：原先是在同一个节点上禁用 `cc.Label` 再挂 `cc.Sprite`，机内不渲染；改成和标题一致的**子节点 `美术字`**（`add_sprite`），标签节点只负责禁用旧 Label。
2. 文字毛边、数字变形：美术字改为 4 倍超采样 + PIL 描边（不再用 MaxFilter 膨胀），落盘 2 倍图（显示尺寸 = PNG/2）；
   位图数字字体从 128 基准提到 256 基准重新绘制，去掉 roll 伪浮雕，小数点 42px（base 256），分隔符不再糊成一团。
3. 按钮不对：改方形圆角（用户要求「改成方形的」），170×62、圆角 9px；贴图按整张 340×124（正好 2 倍）不再九宫格，避免竖向渐变被拉伸出现接缝；深金渐变 + 细描边 + 顶部高光/底部压暗；礼盒换成 128px 扁平矢量稿（深铜色，24px 仍可读）；文案 111×26 放在 x=19。

## 错位根因与修正（2026-11-09）

- 真机截图中统计数字和列表金额同时向上飘，不是 Prefab 坐标错位，而是 `hongli_v8_digits.fnt` 的 BMFont `yoffset` 被写成 `oy - asc`，生成约 `-264` 的负偏移；Cocos 会把位图字形绘制到 Label 节点上方。
- `tools/gen_my_hongli_art.py` 已改为写入图集相对行顶的 `oy`，并重新生成 `assets/V7/hongli_v8_digits.fnt/.png`；当前字形偏移为 4～128，统计数字、未领取金额和明细金额均回到节点中心。
