# 钱包返回来源与充值金额状态

日期：2026-09-13；目录 `/Volumes/SSD/qing`；分支 `main`。保留现有提现配置与美术等未提交修改，未提交、推送、构建或实际交易。

## 问题与修复

- 用户指出从金币流向点击金币充值，关闭钱包会跳大厅；之前的美术检查只验证过入口打开和手动回到金币流向，没有覆盖钱包自动返回来源。现由 `panelMain.ts` 的 `OpenWallet/CloseWallet` 记录并消费来源：金币入口关闭后恢复“我的”及原资金明细覆盖页，刷新余额但保留流水列表、页码和滚动位置；底部钱包入口仍返回发现，牌桌钱包仍走原 UIManager 关闭。
- 同步底栏 Toggle 时屏蔽程序触发的重复切页回调；异步钱包加载防止重复实例，失败恢复来源，离开后旧加载回调失效。
- 第三个金额节点在 `钱包.prefab` 中预设为选中且 Label 是深色。服务器回包虽然设置 `isChecked=false`，原回调却跳过所有取消选中事件，导致 200 元在未选择时仍深色。正式 Prefab 六项初始状态改为全部未选中及浅金字，`apply_v8_wallet_recharge.py` 同步此默认值。
- `panelQianBao.ts` 增加金额状态统一同步：首次进入充值、切换渠道、配置回包时清除选择；用户选中或取消时同步真实 Label 颜色与 checkmark。使用原 Prefab 的选中/未选底图，运行时没有创建美术或重新排版。
- 顺带修复同一金额更新循环的 `arrayAll.Length` 大小写错误：配置数量不足时隐藏无对应值的现有金额节点，恢复较多金额时重新显示；旧渠道回包仍不能覆盖当前渠道。
