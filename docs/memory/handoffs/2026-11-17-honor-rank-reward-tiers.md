# 2026-11-17 后台排行榜名次奖励改成「名次区间 + 奖励」列表（已部署 8891）

- 目录/分支：`/Volumes/SSD/qing`，`codex/club-ui`（改动只在 `XuanManager/web`，不动后端二进制与客户端）
- 目标：排行榜每个榜的名次奖励原来靠「英文逗号分隔的一大串金额」输入，容易打错、看不出第几到第几名；改成和设计稿一致的行列表——每行「最高名次 / 最低名次 / 奖励（元） / 删除」，可新增、删除，展示与编辑同一套列表。**发往服务器和游戏服的数据格式完全不变**（仍是第 1 名起、`100,50,20` 这样的逗号串）。

## 实现要点

- 新增 `XuanManager/web/src/components/RankRewardTiers.tsx`：
  - `tiersFromList(list)`：逗号串 → 区间行，**相邻同额自动合并成一段**（`12888,8888,6888,3888×7` → `1-1 / 2-2 / 3-3 / 4-10`），空串给一行空行。
  - `listFromTiers(tiers)`：按区间展开回逗号串，往返无损。
  - `tiersError(tiers)`：行级校验。因为游戏服按「第 N 项 = 第 N 名」取奖励，**区间必须从第 1 名起首尾相接**——空洞（跳名次）、重叠、没填完、名次 >100、金额非正整数/超 1,000,000 都会在对应档位的列表下方红字提示并拦住提交。
  - `RankRewardTierEditor`：表头（最高名次/最低名次/奖励（元）/操作）+ 行输入 + 「＋ 新增名次区间」。改某行最低名次时，紧跟着的下一行最高名次自动顺延；删行后已填行从第 1 名重新顺排、保留各自跨度。
  - 输入框只收数字（`replace(/[^\d]/g, "")`），避免全角/小数点混进来。
- 两个入口都换成这套列表，行为一致：
  - `HonorRankActivityModal.tsx`（排行榜 → 创建/详情活动弹窗，含手数榜 5 个皮档位）
  - `HonorRankModal.tsx`（俱乐部/联盟行内的排行榜配置）
  - 两处 `Boards` 状态从 `rewards: string[]` 改成 `rewards: RewardTier[][]`（每档一组区间行），提交时 `listFromTiers` 转回原来的 `{dipi, list}` 结构。
- `styles.css` 新增 `.rank-tier-list*` / `.rank-tier-editor*`（浅色后台风格，≥700px 两列卡片、窄屏单列）。
