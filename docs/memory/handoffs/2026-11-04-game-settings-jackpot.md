## 口径

- 服务端 5 档固定顺序：天皇 / 地皇 / 朵皇 / 朵朵 / 丁二皇，默认 20/10/10/2/2。
- UI 第 5 行按用户 2026-11-04 的要求显示「单独丁儿皇」，服务端键是「丁二皇」；字典读写用 `REWARD_TIER_KEYS`，文案用 `REWARD_TIER_LABELS`。
- 改为按池命令后：作用域是当前联盟池 / 独立俱乐部池的 realtime 俱乐部房；权限为联盟总群主或未入盟俱乐部创建者，失败回包会带「你无权管理该奖池」。
