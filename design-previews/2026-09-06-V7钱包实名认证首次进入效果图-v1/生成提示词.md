# V7 钱包首次进入实名认证页生成提示词

用途：纵向手机游戏 UI 效果图，约 941×1672、9:16。

以旧版首次进入钱包页面为功能内容、字段顺序和提示原文依据；以已确认的 V7 钱包提现页为蓝金材质、面板、文字和间距依据；以 V7 后续模块中的交易密码页为战绩式弧形金线顶部及主按钮依据。不要沿用旧图的黑灰视觉。

- 顶部固定为战绩页同款弧形金线：左侧返回箭头，标题“实名认证”，右侧留空。
- 连续高清夜景赌场背景，海军蓝与香槟金，底部只保留克制的扑克牌、筹码装饰；不能有断层、脏切图、平涂深蓝、过黄金色或重阴影。
- 主视觉使用独立、平滑、无锯齿且不拉伸的 8L 盾牌，标题“实名认证与交易密码设置”，副标题“请准确填写身份与收款信息”。
- 主表单为双层细金边的深蓝圆角面板，五行紧凑对齐：
  1. “姓名” / “请输入姓名”
  2. “银行名称” / “请输入银行”
  3. “银行卡号” / “请输入卡号”
  4. “交易密码” / “请输入交易密码”
  5. “确认密码” / “请确认交易密码”
- 主按钮文字“确认提交”，使用中亮蓝到深蓝渐变、细香槟金边、暖白金字；不要金底黑字。
- 下方警示卡标题“重要提示”，完整保留以下原文：
  1. 请填写真实姓名且保证名字准确，设置后名字不能修改。名字错误充值可能损失，同时无法提现。
  2. 只能添加实名对应名下银行卡，其他姓名银行卡无法提现，损失自负。
  3. 交易密码请牢记，一旦忘记无法重置。
  4. 交易密码需和登录密码不相同。
- 不设置底部导航。左右安全边距、顶部固定、中段居中、下方留长屏延展空间；盾牌、图标、美术字单独切图，面板才允许九宫格。
- 中文必须清晰，不重叠、不裁切，不增加功能、示例数据、水印或重复控件。
